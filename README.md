# Rock vs Mine Prediction Using Machine Learning

A Machine Learning classification project that predicts whether an underwater object detected through sonar signals is a **Rock (R)** or a **Mine (M)**.

## Project Overview

This project uses sonar signal data and a Machine Learning classification algorithm to distinguish between rocks and metal mines.

The objective is to train a model that can classify objects based on their sonar signal characteristics.

## Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Scikit-learn
- Matplotlib (if used for visualization)

## Machine Learning Algorithm

**Logistic Regression**

The project imports Logistic Regression from Scikit-learn for binary classification.

## Dataset

The project uses the Sonar dataset.

- 60 numerical input features
- Target labels:
  - R = Rock
  - M = Mine

The dataset is loaded into a Pandas DataFrame for data processing and model training.

## Project Workflow

1. Import required Python libraries.
2. Load the sonar dataset.
3. Explore and understand the dataset.
4. Separate input features and target labels.
5. Split the dataset into training and testing sets.
6. Train the Logistic Regression model.
7. Evaluate model performance.
8. Make predictions on input data.

## Project Files

- `Rock_vs_Mine_Prediction.ipynb` – Google Colab notebook containing the complete ML implementation.
- `README.md` – Project documentation.

## How to Run

1. Open the notebook from this GitHub repository.
2. Click **Open in Colab**.
3. Upload the required Sonar dataset to Google Colab.
4. Run the notebook cells sequentially.
5. View the model predictions and evaluation results.
